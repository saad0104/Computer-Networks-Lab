CSE 614

Computer Networks

Course Outline

Course Overview

This course covers organization and design principles of protocols,infrastructures and services for robust internetworking and end-to-end data communication in networked systems.

Course Instructor

Dr. Atiqur Rahman
Associate Professor
Dept. of Computer Science and Engineering
University of Chittagong

Learning Outcomes

  • Understand the layered architecture of computer networks.
  • Understand the operation of the main components of computer networks.
  • Learn various network protocols and algorithms.
  • Acquire the required skill to design simple computer networks.
  • Become familiar with security risks threatening computer networks.

Course Content

  • Chapter 1Computer Networks and the Internet
  • Chapter 2Application Layer
  • Chapter 3Transport Layer
  • Chapter 4The Network Layer

Topics Covered

Chapter Topics
1Internet, Network Edge, Network Core, Delay, Loss and Throughput in Packet-Switched Networks, Protocol Layers, History of Computer Networking.
2Principles of Network Applications, Web and HTTP, FTP, SMTP, DNS, Peer-to-Peer Applications, Socket Programming.
3Transport-Layer Services, Multiplexing and Demultiplexing, UDP, Reliable Data Transfer, TCP, Congestion Control.
4IP, Routing Algorithms and Routers.

Lab Work

  • Implementing straight through cable.
  • Implementing crossover cable.
  • LAN Switching.
  • Designing a simple web server using socket programming.
